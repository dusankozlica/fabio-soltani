       hero.mp4         (z. B. Laden/Verkäufer, ca. 8–15 Sek.)
       philosophie.mp4  (z. B. Nähmaschine, Teppichreinigung, Nägel einschlagen)
  2. Fertig – die Pfade sind in script.js bereits eingetragen (Variable VIDEOS).
     Zum Abschalten dort einfach '' eintragen -> es bleibt das animierte Foto.

VOR DEM LIVEGANG:
  Beide Clips sind aktuell ca. 5–6 MB. Für schnelle Ladezeiten vor dem
  Deploy auf < 2–3 MB komprimieren (z. B. via Handbrake/CloudConvert,
  720p, H.264). Optional zusätzlich eine .webm-Version für noch kleinere Dateien.
